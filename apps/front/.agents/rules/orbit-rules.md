# Reglas de Desarrollo de Orbit (AuSat)

1. **Identidad**: Proyecto Orbit, equipo AuSat (Universidad Austral).
2. **Modularidad**: Componentes atómicos en `src/components/common` y secciones compuestas en `src/components/sections`.
3. **Estilos**: Usar clases utilitarias de Tailwind CSS v4 con variables CSS temáticas en `src/index.css`.
4. **Animaciones**: Utilizar `motion` para transiciones fluidas de entrada, hover interactivo y pulsos de telemetría.
5. **Iconos**: Importar directamente de `lucide-react`.
