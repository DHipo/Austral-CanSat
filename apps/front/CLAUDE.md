# AuSat - Orbit Frontend Directives

Bienvenido al frontend de **Orbit**, la plataforma web y centro de control de telemetría de **AuSat** (Universidad Austral) para la competencia CanSat 2026.

## Convenciones Principales
- **Tecnología**: React 19, TypeScript, Tailwind CSS v4, `lucide-react`, `motion` para animaciones aeroespaciales fluidas.
- **Identidad de Marca**:
  - Nombre del Proyecto: **Orbit**
  - Equipo: **AuSat** (Universidad Austral)
  - Misión: CanSat 2026 (transporte y entrega de carga delicada con paracaídas y paraglider guiado).
- **Estética**:
  - Tema espacial moderno y sofisticado (dark space `#030712`, glassmorphism, acentos cian `#00e5ff` y esmeralda `#10b981`).
  - Animaciones fluidas que simulan telemetría y dinámicas orbitales.
- **Estructura**:
  - Componentes modulares, tipado estricto en TypeScript y separación clara entre presentación y simulación/estado de telemetría.
